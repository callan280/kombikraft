# Visual asset attribution and scope

BMW AG and the respective original font, graphics and renderer owners retain
all rights in the included assets. They are **not licensed under KombiKraft's
source-code license**. The repository maintainer authorized inclusion and
reported permission to redistribute BMW graphics/fonts; this notice does not
create a replacement license or waive third-party rights. Original asset bytes
and embedded notices are preserved in exported visual resource objects.
Complete embedded font notices are transcribed in [FONT-LICENSES.md](FONT-LICENSES.md).
They include BMW typefaces and the separate Bitstream Vera font license; no
Bitstream font is renamed or modified.

The library contains lossless PNG inspection renders, decoded font files,
known font containers, CE51 meshes/compiled shaders, and Ramses vertex/index/
effect resource records. Fonts, meshes and shaders keep their original stored
bytes. Records explicitly distinguish undecoded visual containers and
unverified channel/orientation interpretations. Hashes, resource names and
source offsets allow comparison with the original assets without publishing
machine paths or complete source firmware. Shader/resource records are data;
this gallery does not execute them or claim a live factory binding.

Source-family labels come from the private extraction inventory. Older F97 ID6
art is distinct from shared KOMBI160/MGU families; a shared M resource does not
establish exact F97 ID7 compatibility. Candidate pictogram groups are derived
from names and do not assert diagnostic meaning or vehicle support.

No original firmware executable, code bank, VM image, vehicle backup, private
inventory, device identity, credentials or user-state database is included.
The exporter and gallery are authored project tools. The assets are the
separate third-party material; no upstream decoder, generated native firmware
array or decompiled program implementation is bundled in this library.
