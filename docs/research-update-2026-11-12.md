# Source update: 12 November 2026

This update publishes the completed contributor tools from recent offline
research. The M Round/Map Touring layouts, visual library and MGU companion
were already current on main; this update does not add vehicle activation to
the Store app.

New source includes original F97 material-reader experiments with a portable
CLI, a NORboot bank extractor, an original MGU proxy-registration probe and
carrier generator, an offline DMA address calculator, and an authored QEMU
memory guard/reset bridge with portable build/admission helpers. Synthetic
tests are included in CI. Firmware-backed checks require matching local inputs
and are not implied by a green public CI run.

Recent findings narrow the remaining work:

- Original material readers resolve the named opacity parameter and Bitmap
  resources, and produce source image-cache keys. Complete graphics loading
  and original GPU equivalence remain unproved.
- Source-selected factory calm mode reaches original gauge callbacks. That
  existing-content path has not become a custom-layout selection interface.
- A concrete MGU SOME/IP operation51 registration path is identified. Runtime
  backend construction and the remote KOMBI receiver join still need proof.
- Original graphics-kernel startup proceeds past CPU admission in a guarded
  experiment; loader boot-information and board dependencies remain. KSS
  research is separately tracing DMA protection/FIQ startup.

Full firmware, proprietary runtime libraries, generated executable carriers,
raw diagnostic captures, credentials and vehicle backups are not part of this
source update. The included visual library keeps its existing separate terms.

No whole-system boot, current-car CAN compatibility, complete factory warning
coverage, custom native activation or validated reversible ECU deployment is
claimed. Those remain prerequisites for a replacement-cluster live test.
