# What currently works

| Area | Evidence and limit |
| --- | --- |
| M Round and Map Touring | Browser layout implementations using locally supplied source graphics. Data and map are illustrative fixtures. |
| Factory graphics | Local assets are checked by byte hashes. Proprietary assets are not in this repository. |
| Original code execution | Private matching-bank experiments execute original constructors, input callbacks, scheduler phases and selected graphics updates. A reusable loader is being integrated. |
| BC/indicator inputs | Bounded original receiver-to-event fixtures have passed. Physical bus sender and current-car route remain unverified. |
| Native custom scene | Private native rendering and save/reload experiments have passed. Package controller logic, production identity, display ownership and warning arbitration are not established. |
| Factory startup | Partial. A genuine missing graphics-backend initialization remains; the all-state authoring frame is not a normal operating cluster. |
| Whole-system emulation | Not demonstrated. GSS application/graphics code is x86-64 with INTEGRITY; KSS companion reset code is ARM. Board devices/reset chain remain unresolved. |
| Car deployment | Disabled. Requires current identity, passive signal validation, complete warning behaviour, fresh backups and a proven reversible route. |

The source archive is a developer preview, not replacement KOMBI firmware.
