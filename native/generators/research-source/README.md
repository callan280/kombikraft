# Historical generator source references

These are the actual authored generator source texts behind the published tables, preserved as .py.txt references rather than misleading executable public commands. They assume the former research directory layout, private source-hash pins and intermediate exports. Sanitized public route metadata intentionally has different JSON hashes. They contain no firmware bank or captured raster payload. Source-specific generation logic and bounds are available for audit and adaptation.

Use ../../generate_f97.py for the working portable public-route F97 generator, and ../../build.py for the full published V12 inputs. Porting every other reference generator to public route packs remains separate work; the current native build consumes their attributed generated results directly. V11 Touring references retain the historical48px footer and no proven navigation provider or physical RPM normalization; they are not the V12 compact40 runtime.
